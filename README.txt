قالب سایت استاتیک فارسی (مناسب GitHub Pages)

فایل‌ها:
- index.html : تمام سایت در یک فایل است و به نصب یا سرور نیاز ندارد.

انتشار در GitHub:
1. یک repository جدید بسازید.
2. فایل index.html را در ریشه repository آپلود کنید.
3. Settings > Pages را باز کنید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. شاخه main و پوشه /(root) را انتخاب و Save کنید.
6. پس از چند دقیقه آدرس سایت در همان صفحه نمایش داده می‌شود.

نکته مهم درباره ایتا:
در حال حاضر دکمه ایتا به https://eitaa.com/09170065486 متصل شده است. اگر شماره تلفن شما نام کاربری ایتا نیست، در فایل index.html عبارت eitaa.com/09170065486 را با لینک یا شناسه واقعی ایتای خود جایگزین کنید.

این یک قالب مشابه از نظر ساختار کلی است، نه کپی دقیق سایت دیگر. کارت‌ها و مشخصات فعلی نمایشی هستند و باید با اطلاعاتی جایگزین شوند که اجازه انتشارشان را دارید.
